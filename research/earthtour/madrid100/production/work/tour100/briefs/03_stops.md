# ブリーフ3：食事（STOP）と料理カードの原稿を書く

「行った気になる100品ツアー」〈都市〉版の、食事（STOP）の原稿を書く。人数が多ければ、日ごとに分けて何人かで書き、あとで1つにまとめる。

## 読むもの
- 旅程と料理の候補：`<記事>/research/dishes.md`（末尾の旅程案が STOP の並び）
- 事実：`<記事>/research/logistics.md`
- 書式の実例：`paris-100-dishes/article.json` と `nyc-100-dishes/article.json` の `stops`（1つの STOP と dishes の全項目を見る）
- 過去の文章監査（同じ間違いをしない）：`paris-100-dishes/review/text.md` の「特に直すべき上位10件」

## 書き出すもの
担当分を `stops` 配列の要素と同じ形の JSON 配列にして `<記事>/parts/stops_<担当>.json` に書く（UTF-8、indent=1）。全部そろったら `article.json` の `stops` に日と時刻の順で入れ、`python3 tour100/build.py check <記事>` を通す。

STOP のキー（全部埋める）：
- `id`：d{DAY}s{通し番号2桁}
- `day`, `time`（"HH:MM"）
- `slot`：朝ごはん／昼ごはん／おやつ／夕ごはん／夜食／一杯
- `area`, `area_en`（写真の検索用の英語）
- `label`：5〜8字
- `title`：カタカナの連続が10文字以上にならないようにする。スマホでは1行が9字ほど
- `subtitle`, `pm`（地図のピンの短い地名）, `lat`, `lng`
- `r`：地図の円の半径（m）。店1軒なら150〜250、界隈なら300〜500
- `place_name`：店名（現地の表記。何軒か回るなら「A → B」）
- `hours`：営業時間と定休日。確かでないものは「出かける前に確かめる」と書く
- `access`：最寄り駅と路線、歩いて何分か
- `info`：[] でよい
- `body`：2〜3段落。1段落100〜160字
- `phrase`：{"en": 現地の言葉の一言, "kana": カナ読み, "ja": 訳}。その STOP で実際に頼む品に合わせる
- `tips`：2つ。{"h", "t"}。body や hours と同じことを繰り返さない
- `move`：{"icon": 🚇🚶🚕⛴️✈️ のどれか, "text": 次の STOP への行き方と所要時間}
- `photo_q`：写真の検索語（英語）を2つ
- `dishes`

料理のキー（全部埋める）：
- `selection`：`SELECTION.md`のkind/reason/distinct/evidence/sources。候補調査の確認済み記録を引き継ぐ。後から理由を創作して埋めない。
- `name`：日本語名。100品で重複しない
- `local`：原語名。写真の検索にも使う
- `gloss`：20〜35字
- `catch`：40〜70字。決めどころを `<mark>…</mark>` で囲む
- `first`：一口目。40〜80字
- `tex`：食感3語
- `how`：食べ方と作法。catch・first・tips と同じことを言わない
- `shop`
- `genre`：次から1〜2個。朝ごはん／パブ／屋台／市場／菓子／飲み物／チェーン店／スーパー／ゲテモノ／移民の味／老舗／ごちそう／軽食
- `taste`：{"甘","塩","酸","辛","コク"} を0〜3で
- `price`：{"seal": 値札の表記, "small": "≈◯円", "unit", "value": 会計に入れる数。幅があれば真ん中, "included": false}。small は、値の真ん中にレートを掛けて10円単位に丸めたもの
- `photo_q`：写真の検索語（英語）を2つ

## 文章のきまり
- 常体（だ・である）で書く。短い文にし、1文で1つのことを言う。
- 読点の打ち方と語順を、誤読されないようにする。表記は STOP の中でもまとめたあとでもそろえる。
- 主役は料理。味、食感、一口目を具体的に書く。店の歴史や豆知識は、1つの STOP に1つまで。
- 「いちばん」「発祥」のような断定は、research に出典があるときだけ書く。宣伝文句や、同じ言い回しの繰り返しは書かない。
- 定休日、曜日、行事は旅程案のとおりに反映する。
- 公開資料をもとにしたモデルコースとして書く。「私」を省いても、編集部や旅の一行が訪問・注文・実食した記録を作らない。味や食感は材料・調理法・資料に基づいて説明する。
- 伝説・由来の異説は「と言われている」などで位置づけを示して残す。未確定であることだけを理由に削除しない。引用・出典は作らない。
- 本文資料は `sources` に資料名と原典URLを記録し、写真クレジットと分ける。
