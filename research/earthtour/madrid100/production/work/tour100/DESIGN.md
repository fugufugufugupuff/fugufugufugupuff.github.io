# tour100 設計書 — 「行った気になる100品ツアー」の型

## 1. 何のための記事か
読者は「行かなくても、行った気になりたい」人。多くはスマホで、上から下へ指で送りながら読む。
記事がかなえること（優先順）：
1. **100品を、写真と一言で次々に見られる**（食べ物図鑑としての楽しさ）
2. **旅の流れに乗れる**（DAY → 時刻 → 場所 → 食べられる料理、の順で進む。公開資料をもとにしたモデルコースであり、編集部の実食記録ではない）
3. **行くときに使える**（行き方、時間、値段、注文の一言、費用）
4. **あとで探せる**（100品もくじ、切手アルバム、地図から、どの料理にも一手で飛べる）

## 2. 構成（上から順に。全記事で同じ）
| # | ブロック | 役割 |
|---|---|---|
| 1 | 表紙 | 地名と「100」を大きく、写真3枚のコラージュ、日数・食事数・品数・予算の4マス |
| 2 | 旅のしおり | DAYごとのカード（時刻・食事の場所・品数）、全体地図、旅の基本情報 |
| 3 | 100品もくじ | 100枚の小さな写真。押すとその料理へ |
| 4 | DAY扉 | その日の色、DAY番号、日付、見出し、その日の料理写真3枚 |
| 5 | 食事（STOP） | その日のルート帯 → 切符型の見出し → 冒頭写真 → 本文と「場所カード」（地図・時間・行き方） |
| 6 | 料理カード | 番号シール・値札・ジャンル印つきの写真 ＋ 名前・原語・キャッチ・一口目・食感・味メーター・食べ方・どこで |
| 7 | まちのようす | 街と店先の写真 |
| 8 | メモ | 注文の一言（吹き出し）＋豆知識2つ（付箋） |
| 9 | 移動の切符 | 次の食事への行き方 |
| 10 | 巻末 | 切手アルバム100枚（チェック欄つき）→ レシート（日別の会計）→ 旅の費用 → 関連リンク → 注記 → 消印 → 出典（写真1枚ごと） |

## 3. 見た目の方針
- **旅のスクラップブック**。明るい紙の地に、ポラロイド、マスキングテープ、番号シール、値札、消印、切符、レシート。雑誌のように明るく、写真が主役
- **装飾は2種類に分ける**
  - 部品の飾り（テープ、シール、値札、切符、消印）：CSS だけで描く。どの国でも同じ
  - 土地の飾り（紋章、植物画、古地図、布の柄）：サイトにアップ済みのパブリックドメイン図版を、テーマごとに差し替える。薄く（不透明度 8〜16%）敷き、文字の読みやすさを邪魔しない
- **色**：テーマ色は3つ（accent・accent2・gold）＋DAYごとの色7つ。本文の文字色はコントラスト比 4.5 以上
- **文字**：見出しは Dela Gothic One、本文は Zen Kaku Gothic New、手書きの差し色に Klee One、原語名に Fraunces（イタリック）、数字とレシートに DotGothic16。見出し・キャプション・料理名は BudouX で文節ごとに改行し、語の途中では切らない
- **スマホを先に作る**（幅 360px を基準にし、768px・1080px で段組みを広げる）。PC は2段組で、料理カードは写真と文字を左右交互に置く

## 4. 仕組み
- **中身**：記事ごとに `article.json` 1つ（書式は README）
- **型**：`templates/`（部品ごとのテンプレート）と `assets/tour100.css`・`tour100.js`
- **国の違い**：`themes.json` のプリセット（色、装飾図版、通貨）。記事では `meta.theme` に名前を書くだけ。足りなければ `theme_override` で一部だけ上書きする
- **サイトへの配信**：CSS は WGE Design System の bundle `t100` としてサイトに1つだけ置く。記事本文には目印 `<!--wge-css:t100-->` を書く。デザインを直すと全記事に反映され、記事を作り直す必要はない
- **写真**：WordPress に取り込んだ画像を使う（外部への直リンクは禁止）。取り込み済みなら srcset（300/768/1024/1536）を自動で付ける

## 5. 自動検査（build のたびに実行）
- 原稿：100品そろっているか、重複、必須項目、写真のライセンス、価格と円換算、写真がWordPressに取り込まれているか
- 画面（`qa.js`）：幅 360・390・768・1280 で開き、次を確かめる
  - ページの横はみ出し、要素の横はみ出し（文字が箱からはみ出していないか）
  - 読み込めない画像
  - 見出しの最後の行が1〜2文字だけになっていないか
  - 画面のスクリーンショット（表紙・しおり・もくじ・DAY扉・STOP・料理カード・メモ・巻末）
