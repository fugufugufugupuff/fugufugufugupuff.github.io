# このフォルダの作業範囲

このフォルダは earthtour.jp「世界グルメ大図鑑」のマドリード100選の引継ぎ資料です。
リポジトリ内の世界ミステリー図鑑の制作・公開タスクではありません。

- 最初に README.md と RUN_TO_COMPLETION.md を読みます。
- source_snapshot/ は受領時点の記録として保全し、更新は work/ 等へ分離します。
- 100項目を勝手に40へ縮小しません。食品と名所の件数を混ぜません。
- 調査、料理実写、権利確認、記事実装、目視検査、WordPress下書き保存までが依頼範囲です。公開・予約公開はしません。
- 同じサイトの最新正本を確認します。資料の閲覧HTMLを制作テンプレートと誤認しません。
- 秘密情報・認証付きURLをGitへ入れません。既存の本番ファイル、別サイト、Actions、Secretsを変更しません。
- API権限不足は迂回せず記録し、独立して進められる工程を続けます。
- このファイルの範囲は当フォルダです。実行環境の上位指示や適用される上位AGENTS.md等に優先するものではありません。
