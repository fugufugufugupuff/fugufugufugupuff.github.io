# マドリード・執筆統合セット

更新：2026-09-28

## 使う順番

1. `Madrid_本文と写真_統合版.html`：スマホ・PCで読める統合ビュー。100項目・優先40表示切替・名所30・写真台帳・出典。画像はネット接続が必要。
2. `01_マドリード100選_紹介文初稿.md`：100項目の紹介文と名所・季節の章。
3. `03_執筆引継ぎ資料.md`：出典と写真、100項目の調査メモ、名所30、未解決事項。Claudeへの主資料。
4. `Madrid_統合調査台帳.xlsx`：並べ替え・確認用の表。長文はMarkdown側で読める。
5. `04_Claudeへの引継ぎプロンプト.txt`：資料と一緒に渡す指示。

`02_優先40選_本文候補.md` は短くするときの参考版。100項目の削除・差し替えではない。

## 内容と状態

100項目の概説本文は合計13,386文字。これに導入、名所の文章、季節表、出典を加えている。文字数は料理本文部分のPython lenで数え、出典URLや管理メモを除外。

名所30、情報源URL86（新規16）、写真台帳52（新規2）。条件付き写真候補43、対応写真候補がある料理等34項目（1項目は片部位のみ）、対象写真未確保66項目。写真配置案は23件。

写真の原画像ファイルは含まない。外部表示や原典リンクはオンラインで開く。43件すべてを今回ゼロから目視したという意味ではなく、今回追加2件と再確認2件以外は前回判定を継承している。権利表示・被写体・撮影地は使用直前に再確認する。

WordPressの更新・公開・画像アップロードは行っていない。100本の個別記事を完成させた資料ではなく、100選の概説を書くための本文・根拠・写真候補をまとめたもの。具体的な店の予約条件や現在の写真が未確保の項目は、調査欄で確認できる。
