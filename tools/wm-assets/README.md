# wm-assets — 世界ミステリー図鑑の背景・装飾素材の使い方

WordPress メディアライブラリに上がっている **背景 46 点・装飾小物 183 点・素材シート 18 点**（計 247 点）を、
記事制作の装置から引けるようにしたカタログ。素材そのものは WordPress 上にあり、ここには URL・寸法・説明だけを置く。

| ファイル | 用途 |
|---|---|
| `catalog.json` | 装置が読む。1 素材 = 1 オブジェクト（url / kind / w / h / alpha / desc / tags / max_css_px） |
| `CATALOG.md` | 人が見る一覧表 |
| `_sheet-*.jpg` | 目視用の一覧シート（背景・小物・ラベル…） |

## 素材の 4 種類

| kind | 何か | 使い方 |
|---|---|---|
| `background` | 全幅の下地。写真系（霧・遺跡・星空）と質感系（紙・石・錆・青焼き） | ヒーローや章区切り帯の `background-image`。上に暗色/明色のグラデを重ねて文字を読めるようにする |
| `texture` | 紙目など薄い質感 | `mix-blend-mode: multiply` で本文背景に薄く敷く |
| `prop` | 透過の小物・ラベル（封蝋・画鋲・テープ・スタンプ・「未解決」プレート等） | 見出し脇、引用ボックスの角、写真のフォトコーナー、年表の点。**原寸より大きく出さない** |
| `sheet` | 複数素材の一枚絵 | 記事には貼らない。足りない小物があれば切り出す |

## 守ること

1. **`max_css_px` を超えて表示しない。** 小物の多くは 100〜400px。ヒーローの主役にはならない。
2. **`tiny`（130px 未満）はアイコン専用。** 見出し脇・箇条書き頭・年表の点。
3. **1 記事で使う小物は 3〜6 点まで。** 多いとスクラップブックの型に見えて、どの記事も同じ顔になる。
4. **背景は記事の題材に合わせて 1〜2 点。** 海の事件に `deep-sea`、文書の謎に `paper-warm`、宇宙に `starfield`。
   合わない背景を無理に使うより、CSS グラデーションだけの方がよい。
5. **同じ組み合わせを連続する記事で使わない。** 直近 3 記事で使った背景・小物は避ける（記事の `design.json` に記録する）。
6. 背景写真の上に文字を置くときは、コントラスト用のオーバーレイを必ず入れる（`linear-gradient(rgba(0,0,0,.55), …)` など）。
7. これらは自サイトの素材なので、写真と違ってクレジット表記は不要。

## 装置からの引き方（例）

```python
import json
cat = json.load(open("tools/wm-assets/catalog.json"))
bgs   = [a for a in cat if a["kind"] == "background" and "dark" in a["tags"]]
seals = [a for a in cat if a["kind"] == "prop" and "seal" in a["tags"] and "tiny" not in a["tags"]]
```

## 更新

WordPress に素材を追加したら `wm-` 接頭辞で命名し、`catalog.json` に 1 行足す（説明とタグを必ず書く）。
一覧シートは `scratchpad/sheets.py` 相当のスクリプトで作り直す。
