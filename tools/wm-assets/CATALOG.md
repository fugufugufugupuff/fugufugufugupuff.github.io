# 世界ミステリー図鑑 素材カタログ（WordPress メディアライブラリ）

`catalog.json` の読みやすい版。装置は JSON を読む。人は表を見る。

- **max_css_px**: その素材を表示してよい最大幅（原寸）。これより大きく表示すると拡大ボケする。
- **tiny**: 130px未満。アイコン用途（見出し脇・箇条書き頭）専用。ヒーローや大きな飾りには使わない。
- **sheet**: 複数素材が並んだ一枚絵。記事に直接貼らない。必要なら切り出してから使う。
